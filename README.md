# Portfólio Web

Esse é meu portfólio pessoal desenvolvido para compartilhar meus principais projetos, habilidades e serviços na área de desenvolvimento web.

## Sobre o projeto

Este portfólio foi desenvolvido com o objetivo de apresentar minha trajetória na área de tecnologia, demonstrar minhas habilidades técnicas e reunir meus principais projetos em um único lugar.

## Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| Vue.js | Construção da interface com componentes reutilizáveis |
| JavaScript | Lógica e interatividade |
| Three.js | Elementos 3D |
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização, responsividade e animações |
| Vite | Ambiente de desenvolvimento e build |
| Vue Router | Gerenciamento da navegação entre páginas |
| Git e GitHub | Versionamento e gerenciamento do código |
